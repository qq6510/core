🚀 Mihomo 内核自动编译与压缩工作流

本项目内置了基于 GitHub Actions 的自动化构建脚本（.github/workflows/build-meta.yml），用于自动拉取 Mihomo 源码、执行交叉编译、应用极限压缩，并将编译产物自动回推到当前仓库中，专为 OpenWrt 路由器环境设计。

本仓库的目标是让用户无需手动编译源码、无需手工处理压缩和解压，只需下载官方兼容格式的内核包，即可直接用于 OpenClash 的“内核更新”功能。

同时，本项目已完整兼容 Cloudflare Warp 的 MASQUE 协议，能够在主流路由器场景中稳定支持更现代的代理接入方式，进一步提升了兼容性与使用体验。

## 🔄 版本升级说明

本项目已完成从 Mihomo v1.19.13 平滑升级至 v1.19.30。此次升级重点提升了内核稳定性、兼容性和性能表现，同时保持与 OpenClash 的高度兼容，减少因版本差异带来的适配问题。

升级内容包括：

- 同步最新 Mihomo Meta 分支代码
- 优化编译参数和交叉编译链配置
- 细化 UPX 压缩策略，进一步降低二进制体积
- 维持 OpenClash 可直接识别的标准压缩包格式
- 完善对 Cloudflare Warp MASQUE 协议的支持与兼容性

## ✨ 核心特性

### ⚡ 全自动跨平台编译
利用 GitHub Actions 的矩阵构建能力，可在同一时间并发编译多种路由器架构的内核二进制，覆盖以下常见平台：

- amd64（x86_64 软路由）
- arm64（ARMv8，如树莓派、R2S / R4S）
- armv7（常见 ARM 硬路由）
- mipsle-softfloat（常见 MIPS 老款路由器，如斐讯、MTK 设备）

### 📦 极限体积压缩（UPX）
针对路由器 Flash 空间有限的问题，构建过程内置了 UPX 壳压缩。默认采用 --lzma --best 的优化参数，并对 MIPS 架构进行兼容性调整，在不影响功能的前提下尽可能减小二进制体积，帮助设备更好地适应有限存储环境。

### ☁️ Cloudflare Warp MASQUE 协议支持
本项目构建的 Mihomo 内核已完美支持 Cloudflare Warp 的 MASQUE 协议，能够在路由器环境中更稳定地接入 Cloudflare 的现代代理方案。该能力可帮助用户在兼容 OpenClash 与路由器平台的同时，获得更优的网络访问体验和更高的协议兼容性。

### 100% 适配 OpenClash
- 内部二进制文件统一命名为 clash
- 对外输出标准的 .tar.gz 压缩包
- 完全符合 OpenClash 面板“内核更新”功能的识别标准
- 下载后可直接在 LuCI 界面中上传替换，无需通过 SSH 进行额外解压或手动配置

### 🤖 自动化回推仓库
构建流程分为两个核心阶段：

1. 并行构建：按架构分别编译并生成压缩包
2. 合并推送：汇总所有产物并自动提交回当前仓库的 mihomo 目录

编译完成后，脚本会自动在仓库根目录创建 mihomo/ 文件夹，并将不同架构的产物统一整理并提交到对应目录，确保版本管理简洁且可追溯。

## ⚙️ 工作流程说明

1. 手动触发：在仓库的 Actions 页面点击 Run workflow 启动构建。
2. 拉取源码：自动从 MetaCubeX/mihomo 的 Meta 分支拉取最新代码。
3. 环境准备：配置 Go 1.22 编译环境，并安装 UPX 压缩工具。
4. 构建与打包：按架构执行交叉编译、UPX 压缩，并打包为 clash-{arch}.tar.gz。
5. 提交与发布：汇总构建产物，利用 GitHub 机器人账号自动提交并推送到仓库的 mihomo 目录中。

## 📁 产物说明

产物会以架构命名的方式保存，例如：

- clash-amd64.tar.gz
- clash-arm64.tar.gz
- clash-armv7.tar.gz
- clash-mipsle-softfloat.tar.gz

这些压缩包可直接用于 OpenClash 的内核更新流程，便于在不同型号路由器中部署和替换。

## ✅ 使用建议

本项目适合希望快速获取稳定、体积更小、可直接部署的 Mihomo 内核版本的用户。无论是软路由、ARM 路由器，还是老款 MIPS 设备，都可以通过本仓库的自动化流程快速获取对应的二进制文件。

如果你希望持续跟进最新内核版本，本项目的自动化构建机制可以帮助你在最短时间内完成更新与回推。
